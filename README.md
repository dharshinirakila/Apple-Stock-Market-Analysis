Apple Stock Market Analysis

Project Overview

This project focuses on analysing Apple's (AAPL) stock market data using Python and Power BI. Stock data was collected using the yfinance library and analysed to understand daily stock price movements, returns, and market trends.

Tools & Technologies

- Python
- yfinance
- Power BI
- Power Query
- DAX

Data Collection

- Retrieved Apple stock market data using the yfinance Python library.
- Used stock price details such as High, Low, and Date for analysis.
- Prepared additional columns for Daily Return Percentage and Daily Price Range.

Key Analysis

- Analysed daily stock price movements.
- Calculated Daily Return Percentage to understand price changes.
- Examined Daily Price Range using High and Low prices.
- Visualized stock market trends and price movements.
- Explored stock volatility and market fluctuations.

Power BI Dashboard

Created an interactive Power BI report with two pages to visualize Apple stock market data and analyse price movements and trends.

Project Objective

To understand stock market movements and identify price trends through Python-based data analysis and interactive Power BI visualizations.
